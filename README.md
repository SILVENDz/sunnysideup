## Sunny Side UP
Sunny side UP simple solo or two-player beach volleyball, game with movement, bumping, and scoring features. The inspiration behind this is what I personally consider a "perfect day". Volleyball with my beloved friends is something that I treasure deeply, and I wanted homage that through a cozy little game we can play together even if indoors,

## Features:
* Able to be played by two people on the same computer (Player one uses WASD keys while Player 2 uses the arrow keys)
* Each ball on the opposite side earns a point for the player
* After 21 points, the game shows a win screen
* Player can choose to restart the game by pressing the backspace button
* Cute drawings for bunny lovers!
## How it works:
* Used sprites, character bodies, and collision bodies in order to create the bunnies that you play with! The collision bodies allowed the ball to bounce off once they came in contact with the sprites.
* Used GDScript in order to code the sprite's movement. The sprites can only move left, right, and up so that there are no problems with the over collisions on the fore and background.
* I used a rigid body for the volleyball in order for it to have physics features (such as customizable gravity and bounce) and for it to be able to be moved around by the characters.
