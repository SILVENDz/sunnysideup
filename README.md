Sunny Side UP
A simple solo or two-player beach volleyball, game with movement, bumping, and scoring features.
<img width="1317" height="986" alt="Screenshot 2026-09-04 at 11 03 17 PM" src="https://github.com/user-attachments/assets/4996649e-6c7e-4054-aafb-92b804b92124" />
Demo: https://silvendz.itch.io/sunny-side-up
-Able to be played by two people on the same computer (Player one uses WASD keys while Player 2 uses the arrow keys)
-Each ball on the opposite side earns a point for the player
-After 21 points, the game shows a win screen
-Player can choose to restart the game by pressing the backspace button
